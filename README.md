# 診療支援カレンダー

医療機関の受付・診察室で使うための、日数計算つきカレンダーです。HTML ファイル 1 枚で動く PWA（ホーム画面に追加できる Web アプリ）で、外部ライブラリやビルドは不要です。オフラインでも動作します。

## 機能

- **日数計算**：今日から 7・14・28・56・84 日後の日付を表示（処方日数の目安）。任意の日数も入力して計算できます。
- **休診日の警告**：計算した日付が休診日の場合は「⚠ 休診日」と、次の診療日を表示します。
- **カレンダー**：月送り表示。日付をタップすると「今日から何日後（何日前）」を表示します。
- **祝日の自動計算**：日本の祝日（振替休日・国民の休日を含む）を自動で表示します。祝日には「営業／休診」ラベルが付きます。
- **医院設定**：医院名（画面タイトルに表示）と定休日（休診曜日）を設定できます。
- **臨時休日**：年末年始・夏季休暇などを期間で登録・削除できます。
- **書き出し／読み込み**：設定と臨時休日を JSON ファイルで保存・復元できます。
- **日付の自動更新**：画面を開いたまま日付が変わっても、0 時過ぎやアプリへの復帰時に自動で表示を更新します。

## 使い方

`index.html`・`sw.js`・`manifest.json`・アイコン画像を、任意の静的ホスティング（GitHub Pages、社内 Web サーバー等）に置くだけで動作します。サーバー側のプログラムやデータベースは不要です。

スマートフォンでは、ブラウザの「ホーム画面に追加」でアプリのように使えます。

## 設定項目

右上の「⚙️」から設定できます。

| 項目 | 内容 |
| --- | --- |
| 医院名 | 画面タイトルに「{医院名} 診療支援カレンダー」として表示（空欄可） |
| 休診曜日 | 定休日の曜日。初期設定は日曜・月曜 |
| 臨時休日 | 日付（期間）と名前を登録 |

設定はすべて端末内（ブラウザの localStorage）に保存されます。端末やブラウザごとに個別の設定になります。

## データの取り扱い

- 患者データは一切扱いません。
- 入力した設定・臨時休日を外部へ送信することはありません（通信はアプリ本体ファイルの取得のみ）。

## 他院での導入手順

1. ファイル一式を自院用の静的ホスティングに配置します。
2. アプリを開き、「⚙️」→「医院設定」で医院名と定休日を設定して保存します。
3. 必要に応じて、「データ管理」→「読み込み」で、別端末から書き出した JSON ファイル（`calendar-settings.json`）を読み込みます。
